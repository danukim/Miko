# Miko Audio Streaming Integration Guide

This guide shows how to integrate real-time audio streaming with your Miko AI assistant and Unity desktop avatar.

## Overview

The new system allows you to:
1. ✨ Stream audio chunks in real-time to Unity as they're generated
2. 🎤 Maintain perfect lip-sync with the generated speech
3. ⚡ Keep low latency for responsive avatar animations
4. 🔄 Play muted audio locally for timing purposes (like your previous setup)

## Integration Steps

### 1. Update Your Miko Audio Playback Function

Replace your existing `audio_playback_thread` function in `MITSUHAVR_Ollama.py`:

```python
# Add this import at the top of your file
from audio_streamer import create_miko_audio_handler

def audio_playback_thread(audio_queue: queue.Queue, sample_rate: int):
    """
    Enhanced audio playback thread that streams to Unity while playing locally for timing
    """
    # Create dual audio player (local muted + Unity streaming)
    dual_player = create_miko_audio_handler(
        server_url="http://localhost:8000",
        local_volume=0.0  # Muted for timing only - Unity handles actual playback
    )
    
    dual_player.start_playback(sample_rate)
    
    try:
        fragment_num = 0
        while True:
            try:
                # Get audio fragment from TTS generation queue
                audio_fragment = audio_queue.get(timeout=1.0)
                
                if audio_fragment is None:  # Shutdown signal
                    break
                
                # Stream to Unity and play locally (muted) for timing
                dual_player.add_audio_chunk(audio_fragment)
                
                fragment_num += 1
                
            except queue.Empty:
                continue
            except Exception as e:
                print(f"❌ Audio playback error: {e}")
                break
                
    finally:
        dual_player.stop_playback()
        print("🎵 Audio playback thread terminated")
```

### 2. Unity Setup

1. **Add the MikoAudioReceiver script** to your avatar GameObject
2. **Configure the AudioSource** component (it will be created automatically if not present)
3. **Set up your lip sync component** by extending the `AudioLipSync` class
4. **Configure the server URL** in the inspector (default: http://localhost:8000)

### 3. Lip Sync Integration

If you have an existing lip sync system, modify it to inherit from `AudioLipSync`:

```csharp
public class YourExistingLipSync : AudioLipSync
{
    // Your existing lip sync fields and methods
    
    public override void OnSpeechStart()
    {
        // Called when Miko starts speaking
        // Initialize your lip sync system
    }
    
    public override void OnSpeechEnd()
    {
        // Called when Miko stops speaking
        // Reset mouth to closed position
    }
    
    public override void OnAudioData(float[] audioData, float volume)
    {
        // Called for each audio chunk with volume data
        // Update your lip sync based on the audio volume
        // volume is normalized (0.0 to 1.0)
    }
}
```

## Key Benefits

### ✨ Real-time Streaming
- Audio chunks are sent to Unity as soon as they're generated by GPT-SoVITS
- No need to wait for complete audio file generation
- Significantly reduced latency

### 🎤 Perfect Synchronization
- Local audio plays muted for timing (like your previous setup)
- Unity receives the same audio data for actual playback
- Lip sync is driven by real audio data, not approximations

### ⚡ Low Latency
- Streaming starts as soon as first audio chunk is ready
- No file I/O delays
- Responsive avatar animations

### 🔄 Backward Compatibility
- Maintains the timing mechanism you were using before
- Easy to fall back to file-based approach if needed
- Works with your existing TTS pipeline

## Troubleshooting

### Connection Issues
```python
# Test the audio streamer independently
python audio_streamer.py
```

### Unity Not Receiving Audio
- Check Console for connection errors
- Verify server URL in Unity inspector
- Ensure Windows Firewall allows connections

### Audio Quality Issues
- Adjust `bufferSizeSeconds` in Unity (default: 5 seconds)
- Check sample rate matching between Python and Unity
- Monitor network latency

## Advanced Configuration

### Custom Audio Processing
You can add audio effects or processing by modifying the `OnAudioChunkReceived` method in Unity:

```csharp
void OnAudioChunkReceived(string audioDataBase64, int sampleRate)
{
    // ... existing code ...
    
    // Apply custom audio processing here
    audioFloats = ApplyCustomEffects(audioFloats);
    
    // ... rest of the method ...
}
```

### Multiple Avatar Support
The server supports multiple Unity clients simultaneously. Each connected avatar will receive the same audio stream.

### Performance Optimization
- Adjust chunk sizes in the audio streamer for your specific use case
- Use the `local_volume` parameter to control local playback volume
- Monitor memory usage with large audio buffers
