# MITSUHA-development

This repository contains the development version of the MITSUHA AI Assistant project.

## Key Files

- `MITSUHAVR_Ollama.py`: Main application script.
- `app.py`: Server application.
- `audio_streamer.py`: Audio streaming module.
- `GPT_SoVITS/`: Voice synthesis models and tools.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Configure `.env` with your API keys and settings.
3. Run the application: `python MITSUHAVR_Ollama.py`
