## 🎀 About

This repository houses the development version of the **MITSUHA AI Assistant**, a powerful yet adorable virtual companion designed to bring your desktop to life! 

## 🌸 Key Features

- **🎤 Voice Magic**: Talk to Mitsuha naturally using advanced speech recognition!
- **🔊 Audio Sparkles**: Crystal clear audio processing for that perfect voice.
- **🔥 AI Power**: Powered by PyTorch and Transformers for big brain energy!
- **🤖 Smart Models**: Uses cutting-edge NLI models for understanding your intent.
- **🏠 Smart Home**: Control your Tuya smart devices with just your voice!
- **🧠 Memory Core**: Remembers your conversations using VectorDB.
- **🦙 AI Chat**: Integrated with Ollama for endless intelligent conversations.
- **🎵 Voice Synthesis**: Beautiful voice generation using GPT-SoVITS.

## 📁 Magical Files

- **`MITSUHAVR_Ollama.py`**: The heart and soul of Mitsuha! This is the main script that brings her to life.
- **`app.py`**: The bridge between dimensions (Server Application).
- **`audio_streamer.py`**: Streams Mitsuha's voice to the Unity avatar.
- **`GPT_SoVITS/`**: The treasure chest of voice models and tools.
